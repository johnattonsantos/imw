# Internacionalizacao do sistema

Idiomas suportados:

- `pt_BR` - Portugues Brasil
- `pt_PT` - Portugues Portugal
- `en` - Ingles
- `fr` - Frances
- `it` - Italiano
- `es` - Espanhol
- `ja` - Japones

## Como adicionar textos novos

Ao criar um novo modulo, tela, botao, campo ou mensagem, nao deixe o texto fixo no Blade, Controller ou Service.
Toda mensagem que hoje esta em portugues deve refletir o idioma escolhido no select. Para isso, a mensagem precisa passar por `__()` e existir nos arquivos de traducao.

Use uma chave de traducao:

```php
__('app.fields.name')
__('app.actions.save')
__('app.navigation.reports')
```

Depois cadastre a mesma chave em todos os arquivos:

```text
lang/pt_BR/app.php
lang/pt_PT/app.php
lang/en/app.php
lang/fr/app.php
lang/it/app.php
lang/es/app.php
lang/ja/app.php
```

Para mensagens antigas que ainda estao escritas diretamente em portugues, cadastre a frase nos arquivos JSON do idioma:

```text
lang/en.json
lang/fr.json
lang/it.json
lang/es.json
lang/ja.json
lang/pt_PT.json
```

Exemplo:

```json
{
  "Registro atualizado.": "Record updated."
}
```

## Sessao

O idioma escolhido fica salvo em sessao na chave configurada em `config/locales.php`.
Ao deslogar, a sessao e limpa e o idioma volta ao padrao do sistema no proximo login.

## Auditoria

Use os scripts abaixo para manter a internacionalizacao completa:

```bash
php scripts/i18n_audit.php
php scripts/i18n_missing.php
```

O primeiro procura textos estaticos em Blade/PHP e atualiza o catalogo `pt_BR`.
O segundo informa se algum idioma esta sem traducao.

Para converter novos textos estaticos de Blade/PHP/JS para `__()`, use:

```bash
php scripts/i18n_apply_blade.php
php scripts/i18n_apply_php.php
python3 scripts/i18n_apply_js.php
```

Para preencher traducoes faltantes com traducao automatica:

```bash
python3 scripts/i18n_translate_missing.py
```

Depois rode sempre:

```bash
php artisan view:cache
php scripts/i18n_missing.php
```
